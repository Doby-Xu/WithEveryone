# WithEveryone：面向群像生成的统一规划与身份锚定

[![arXiv](https://img.shields.io/badge/arXiv-2510.14975-b31b1b.svg)](https://arxiv.org/abs/2510.14975)

[English](README.md) | [简体中文](README_CN.md)

**让每个人都在画面中清晰可辨。**

WithEveryone 面向五至十个参考身份生成协调统一的群像，同时准确保留每个人的身份。

![WithEveryone 效果展示](assets/teaser.png)

## 🔥 核心方法

**逐一寻址身份。** 每张参考图都被编码为专属身份令牌。

**生成前先规划。** 身份感知布局推理统一安排画面中的每个人。

**精准监督人脸。** 布局锚定身份损失在目标区域施加对应身份监督。
